# Onboarding

A newcomer should be able to install prerequisites, configure synthetic data, run
the app, and execute tests using the repository instructions. Pair on the first
run if possible, and record every missing instruction.

Grant only the access required for the role. Put access requests through the
organization's existing process; never exchange secrets in an issue or README.
Choose a first contribution with a narrow acceptance criterion. Ask the newcomer
to improve one setup instruction as part of that contribution.
